# ESL-project

## Сборка и прошивка

Запустите `make dfu` из каталога проекта. Цель сначала проверяет и собирает
`nrf52840_xxaa`, затем заново создает `_build/nrf52840_xxaa.dfu` из актуального
HEX-файла и запускает USB DFU.

Пока кнопка SW1 не нажата, горит красный светодиод — это заметный индикатор,
что приложение запустилось. При нажатии SW1 включается последовательность RRGGGB.

По умолчанию ожидание перед подключением к DFU-порту отключено. Если устройству
нужно время для перехода в режим DFU, задайте задержку, например:

```sh
make dfu DFU_CONNECT_DELAY=3
```

Для другого serial-порта используйте `make dfu DFU_PORT=/dev/ttyACM1`.
